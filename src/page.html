USB-C Dock Failure, Explained

HP USB-C Dock G5 on a Windows business laptop. Charging kept working, but USB, Ethernet and displays vanished, and the dock didn’t appear in Device Manager at all. A restart didn’t help. Holding the power button for about 45 seconds brought everything back.

C · The reset

FIG 06

Why a Windows restart may not fix it

SPLIT SCREEN

Restart is a warm reset of the CPU and OS. With Fast Startup, Windows “Shut down” is a hybrid hibernate. With a dock attached, the PD controller must stay powered to keep charging, so neither path is guaranteed to clear it.

    Root-cause hypothesis map

    CLICK A HYPOTHESIS

    Green means consistent with the evidence, not proven. The dock’s absence from Device Manager moved the scoring. USB 2.0 needs no Alt Mode and bypasses the mux, so Alt Mode or the mux alone can’t explain it. The break is earlier, in the connection state the PD controller reports.
